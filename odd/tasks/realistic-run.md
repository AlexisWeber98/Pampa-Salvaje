# Realistic run

Replace the protagonist's run (the `jog` clip in `assets/characters/animations/humanoid.glb`) with a real runner's.
Branch `feat/realistic-run`; delivery `ask-on-risk`; runners `python3 -m unittest discover -s tools -p test_retarget.py` and `cargo test -p pampa-render --lib character::`.

## Specs

- S1 (L2): "reemplazar animacion de correr (parece supréroe) por una realista". Source: CMU motion capture (user's choice), retargeted by `tools/retarget.py`.
- S2 (L4): it must not run "como maricón que se está orinando": no mincing quick steps, knees together, feet in line or hands at the chest.
- S3 (L6, `Videos/correr.mp4`): "eso no es correr, nadie corre así en su sano juicio". No crouch: the 127_07 capture ran with a 36° torso lean and 57° stance knee.

  - "TRONCO — Inclínalo entre 5° a 15°";

  - "PIERNAS — Sepáralas entre 70° a 100°";
  - "TRANQUIL@ — Todo esto lo logras si te concentras en que tus pies vayan hacia atrás".
- S5 (L8): the run speed stays at 5 m/s ("Mantener 5 m/s").
- S7 (L13): the run matches the user's 8-pose drawn run cycle ("asi debe verse un ciclo de carrera completo, compara las imagenes que te pase (los 8 tiempos) con los que tenemos para acomodarlo"): head over the chest, wide arm swing (fist up to the chin in front, elbow well behind), the knee driven up nearly level.
